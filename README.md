# Blender-Helper-Scripts

**ResetShapeKeys**

Sets all shape keys except Basis of the active object to zero

**Remove Shape Key Drivers**

Bulk remove drivers from shape keys

**RemoveAllShapekeysExceptSelected**

Deletes all shape keys except Basis and the active one

**MoveToFolders**

"Moves all selected armatures/empties and their child objects into individual collections named after each root object.
